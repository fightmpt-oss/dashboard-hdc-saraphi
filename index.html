สำรวจแคตตาล็อกรายงาน Open Data กระทรวงสาธารณสุข (1,028 รายงาน)

ระบบเปิดเผยข้อมูลสาธารณสุข สำนักงานปลัดกระทรวงสาธารณสุข ครอบคลุม 5 หมวดหมู่หลัก และ 51 หมวดหมู่ย่อย พร้อมตัวอย่าง Code สำหรับนักพัฒนาในการดึงข้อมูลผ่าน REST API
